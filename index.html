Rotating Tunnel Illusion

Step-by-step tutorial guide.

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Rotating Tunnel Illusion</title>
<style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { width: 100vw; height: 100vh; overflow: hidden; background-color: #2b2b2b; display: flex; justify-content: center; align-items: center; }
    canvas { display: block; }
</style>
</head>
<body>
<canvas id="illusionCanvas"></canvas>
<script>
    const canvas = document.getElementById('illusionCanvas');
    const ctx = canvas.getContext('2d');
    let width, height;
    function resize() {
        width = canvas.width = window.innerWidth;
        height = canvas.height = window.innerHeight;
    }
    window.addEventListener('resize', resize);
    resize();
    const numSquares = 14;
    let time = 0;
    function draw() {
        ctx.clearRect(0, 0, width, height);
        const centerX = width / 2;
        const centerY = height / 2;
        const maxRadius = Math.min(width, height) * 0.4;
        for (let i = 0; i < numSquares; i++) {
            const scale = 1 - (i / numSquares) * 0.75;
            const size = maxRadius * scale * 2;
            const rotation = Math.sin(time - (i * 0.2)) * (Math.PI / 3);
            const hue = 330 - (i / numSquares) * 300;
            const color = `hsl(${hue}, 100%, 65%)`;
            ctx.save();
            ctx.translate(centerX, centerY);
            ctx.rotate(rotation);
            ctx.strokeStyle = color;
            ctx.lineWidth = 1.5;
            ctx.setLineDash([2, 4]);
            ctx.beginPath();
            ctx.rect(-size / 2, -size / 2, size, size);
            ctx.stroke();
            ctx.setLineDash([]);
            const dotRadius = 4.5;
            const corners = [
                { x: -size / 2, y: -size / 2 },
                { x: size / 2, y: -size / 2 },
                { x: size / 2, y: size / 2 },
                { x: -size / 2, y: size / 2 }
            ];
            corners.forEach(corner => {
                ctx.fillStyle = color;
                ctx.beginPath();
                ctx.arc(corner.x, corner.y, dotRadius, 0, Math.PI * 2);
                ctx.fill();
                ctx.fillStyle = '#ffffff';
                ctx.beginPath();
                ctx.arc(corner.x, corner.y, dotRadius * 0.3, 0, Math.PI * 2);
                ctx.fill();
            });
            ctx.restore();
        }
        time += 0.015;
        requestAnimationFrame(draw);
    }
    draw();
</script>
</body>
</html>

HTML Quick Reference & Learning Guide

Comprehensive explanations and copyable examples for core HTML concepts.

1. Document Boilerplate

Every HTML file starts with a standard structure defining document type, language, head config, and body content.

  • <!DOCTYPE html> Defines HTML5 document.
  • <html> <head> <body> Core structural skeleton.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Page</title>
</head>
<body>
    <h1>Hello World!</h1>
</body>
</html>

2. Text & Typography

Used for titles, paragraphs, line breaks, and emphasizing text styles.

  • <h1> to <h6> Headings (H1 is biggest).
  • <p> Paragraph block.
  • <strong> / <em> Bold and italic emphasis.
<h1>Main Heading</h1>
<p>This is a <strong>bold</strong> paragraph.</p>
<br> <!-- Line Break -->

3. Links & Media

Connect pages using anchor links and embed images or media assets.

  • <a href="..."> Hyperlink to other pages/sites.
  • <img src="..." alt="..."> Embed image files.
<a href="https://google.com" target="_blank">Visit Google</a>
<img src="logo.png" alt="Site Logo">

4. Lists (Ordered & Unordered)

Organize item groups with bullet points or numbered numeric lists.

  • <ul> & <li> Unordered bullet list.
  • <ol> & <li> Ordered numbered list.
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

5. Tables

Display tabular data using rows (`tr`), headers (`th`), and cells (`td`).

  • <table>, <tr>, <th>, <td> Grid data tags.
<table border="1">
    <tr><th>Name</th><th>Skill</th></tr>
    <tr><td>Rahul</td><td>Frontend</td></tr>
</table>

6. Forms & Inputs

Collect user input data like text, emails, password fields, and submit buttons.

  • <form> & <input> Interactive inputs.
  • <button type="submit"> Action trigger.
<form>
    <input type="email" placeholder="Enter email">
    <button type="submit">Submit</button>
</form>
